# Computer Vision in Fitness: Evaluating Two-Handed Dumbbell Romanian Deadlift Form

**Team Member:** Michael Bowman  
**Program:** Dumbbell Romanian Deadlift Form Analyzer

## Project Description

This project uses Python and Google MediaPipe Pose to analyze still images of the two-handed dumbbell Romanian deadlift. The images are contained in a PDF dataset that is processed by the program. MediaPipe detects body landmarks and calculates three measurements at the bottom position of the movement:

- Hip angle
- Knee angle
- Torso lean

The measurements are compared with predetermined angle ranges to identify whether each position is within the expected range. The program also creates annotated images and a batch summary table showing the results.

## Dataset

The dataset consists of one PDF containing 17 still images of the bottom position of the two-handed dumbbell Romanian deadlift. Eleven images were created by the author, and six images were obtained from publicly available online sources for educational analysis.

The program processes the images contained in the PDF and uses MediaPipe Pose to identify body landmarks and calculate the hip angle, knee angle, and torso lean.

## How to Run the Project

### Google Colab

1. Download or clone this GitHub repository.
2. Open `RDL_Form_Analyzer.ipynb` in Google Colab.
3. Run the notebook cells in order.
4. When the file-selection window appears in Cell 6, select `Combinedpictures.pdf`.
5. The program will convert each of the 17 PDF pages into an image and analyze them individually.
6. Review the original and annotated images, angle measurements, and batch summary generated by the notebook.
